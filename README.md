# BREACHFRAME

BREACHFRAME is a modern side-scrolling action-platformer built as a self-contained browser game.

Guide Rook, a rescue android, through a city whose emergency network has turned hostile. Defeat three guardian machines, recover their weapons, and climb the Crown Relay to restore the city.

## Play

GitHub Pages:
https://skabkleveta-creator.github.io/Breachframe/

## Features

- Responsive side-scrolling action-platforming
- Three selectable districts plus a final stage
- Guardian bosses with weapon weaknesses
- Chargeable cannon and unlockable special weapons
- Keyboard, touch, and gamepad support
- Mobile portrait and landscape layouts
- Local save progression
- Procedural/vector-style visuals and generated audio
- Single-file deployment

## Controls

- A / D or Arrow Keys — Move
- Space / Z — Jump
- J / X — Fire / charge
- Shift / C — Dash
- Q / E — Cycle weapons
- Esc — Pause

Touch controls are available on supported mobile devices.

## Deployment

The game is contained in `index.html` and is designed to run directly from GitHub Pages with no external dependencies.
